# Rekomendasi Keyword Pinterest untuk Inspirasi Visual Gong Cha

Agar hasil pencarian di Pinterest tidak memunculkan desain spin wheel yang norak / bergaya kasino warna-warni, gunakan kombinasi kata kunci berbasis **luxury branding, tea culture, editorial web design, dan gamification UI**.

---

## 1. Untuk Desain Landing Page & Hero Section (Mewah & Elegan)
Keyword ini akan menampilkan layout web berkelas, tipografi serif, dan palet warna merah marun/emas:
- `luxury beverage web design`
- `tea brand landing page ui`
- `editorial mobile web design`
- `burgundy and gold branding luxury`
- `chinese tea brand visual identity`
- `asian tea house modern branding`
- `grand opening digital invitation mobile ui`

---

## 2. Untuk Roda Keberuntungan (Spin Wheel yang Berkelas & Elegan)
*Catatan:* Jangan hanya ketik "spin wheel", karena Pinterest akan menampilkan game karnaval. Tambahkan kata kunci kriya/luxury:
- `luxury fortune wheel ui`
- `vintage wheel of fortune design aesthetic`
- `gold wheel ui design gamification`
- `chinese new year lucky wheel luxury`
- `oriental roulette ui gold`
- `minimalist spin wheel app ui`
- `gamification reward mobile ui luxury`

---
